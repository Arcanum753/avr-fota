Справка: CRON-выражения (расписание)

Расписание задаётся выражением из 6 полей (интерпретатор всегда ждёт секунды в первом поле):

секунды   минуты   часы   день-месяца   месяц   день-недели

Значения: секунды 0–59, минуты 0–59, часы 0–23, день месяца 1–31, месяц 1–12 (или JAN–DEC), день недели 0–7 (0 и 7 — воскресенье; SUN–SAT). Возможно 5 полей (без секунд — они станут 0) и 7 полей (дополнительно год).

Синтаксис одного поля:

  • * — любое значение;
  • */N — каждые N (в секундах */10 — каждые 10 секунд);
  • a-b — диапазон, a-b/N — диапазон с шагом N;
  • a,b,c — список значений;
  • ? — то же, что *.

Примеры правил в сценарии:

cron {*/10 * * * * *} { ... }    # каждые 10 секунд
cron {0 * * * * *}     { ... }    # каждая минута (в 0-ю секунду)
cron {15 42 * * * *}   { ... }    # каждый час в 00:42:15
cron {0 0 9 * * 1-5}   { ... }    # будни в 09:00:00
cron {30 6 1 * *}      { ... }    # 1-го числа каждого месяца в 06:00:30
# --- по часам и «раз в N часов» ---
cron {0 0 * * * *}     { ... }    # каждый час в 00:00:00
cron {0 0 */2 * * *}   { ... }    # каждые 2 часа (00:00, 02:00, 04:00, ...)
cron {0 30 */4 * * *}  { ... }    # каждые 4 часа в :30 (00:30, 04:30, ...)
# --- по дням недели (0 = воскресенье, 1 = понедельник, ...) ---
cron {0 0 9 * * 1}     { ... }    # по понедельникам в 09:00
cron {0 0 9 * * 1,2,4} { ... }    # по понедельникам, вторникам и четвергам в 09:00
cron {0 0 9 * * 1-5}   { ... }    # по будням (пн-пт) в 09:00
# --- по числам месяца ---
cron {0 0 9 2-30/2 * *} { ... }   # чётные числа месяца в 09:00
cron {0 0 9 1-31/2 * *} { ... }   # нечётные числа месяца в 09:00
cron {0 0 9 5 * *}     { ... }    # 5-го числа каждого месяца в 09:00
cron {0 0 9 */5 * *}   { ... }    # каждое 5-е число (1,6,11,...) в 09:00
# --- диапазон времени (например, с 9 до 17 часов) ---
cron {0 0 9-17 * * *}  { ... }    # каждый час с 09:00 до 17:00 включительно
cron {0 30 9-17 * * *} { ... }    # каждый час в :30 с 09:30 до 17:30
cron {0 0 9-17 * * 1-5} { ... }   # будни, каждый час с 09:00 до 17:00

Cron срабатывает только после синхронизации времени по NTP; выражения считаются в локальном времени устройства. Готовые примеры — файлы ex_10s.tcl, ex_1m.tcl, ex_minsec.tcl.

Справка: язык сценариев (Tcl)

Файл /macros/<имя>.tcl — это сценарий на Tcl. Правила регистрируются при запуске/перечитывании файла; остановленный сценарий не исполняется. Все правила файла работают в одном интерпретаторе (переменные и proc общие).

Регистрация правил (команды верхнего уровня):

  • cron {выражение} {тело} — по расписанию (см. справку CRON);
  • cond {условие} {тело} — выполняется при переходе условия «ложь → истина» (проверка раз в секунду);
  • button {имя} {тело} — внешний вызов: macro btn имя;
  • term {слова...} {тело} — сообщение из терминала: macro msg слова... (совпадение по всем словам).

Команды и значения:

  • set имя значение и обращение $имя;
  • proc имя {аргументы...} {тело} — свои функции;
  • if, while, return, break, continue;
  • puts текст — печать в терминал с префиксом [MACRO];
  • now — текущие секунды; clock — время «ЧЧ:ММ:СС»;
  • арифметика и сравнения: + - * /, > >= < <= == !=;
  • [команда] — подстановка результата, {...} — группировка без подстановки, "..." — с подстановкой, # — комментарий до конца строки.

Простой пример сценария:

# считаем и выводим тики каждые 10 секунд
set ticks 0

proc say {msg} {
    puts [clock]
    puts $msg
}

cron {*/10 * * * * *} {
    set ticks [+ $ticks 1]
    say {fired: every 10 seconds}
}

cond {[>= $ticks 6]} {
    say {fired: already 6 ticks}
}

Условие считается истинным, если результат не равен 0. Полный пример правил ввода — файл ex_input.tcl.
