# Example scenario for module_macros (prototype)
# Triggers: cron <6-field expression> : <action>
#           button <name> : <action>
#           term <word> : <action>
# cron: <sec> <min> <hour> <dom> <month> <dow> (5 fields - no seconds)
# The fired action is printed to the serial terminal.
cron */10 * * * * * : Cron fired: every 10 seconds
cron 0 * * * * * : Cron fired: every minute
button test : Button test pressed on the web page
term hello : Got 'hello' message from the terminal
